# Task Tracker

This repository contains a Task Tracker application implemented as a solution for the project listed on [roadmap.sh](https://roadmap.sh/projects/task-tracker-js).

## Project structure

- `Backend/` - Node.js backend with Express and MongoDB support.
- `Frontend/` - React + Vite frontend.

## Notes

- This project is built as the solution for the Task Tracker project described at https://roadmap.sh/projects/task-tracker-js.
- Right now, the backend is not connected to the frontend.
- Backend and frontend integration will be completed and updated later.

## Getting started

### Backend

1. Open `Backend/`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the backend server:
   ```bash
   npm run dev
   ```

### Frontend

1. Open `Frontend/`
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the frontend dev server:
   ```bash
   npm run dev
   ```

> Note: Frontend/backend integration is pending and will be added in a later update.
